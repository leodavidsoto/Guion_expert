# Guion Expert Webapp (Dev-Tool)

**Importante:** Esta interfaz basada en Flask y HTML/JS vanilla es estrictamente una **herramienta de desarrollo interno y debug**. 

El frontend oficial de cara al usuario final es **Studio Next.js** (ubicado en `i2V/apps/web`).

## Uso Local

Esta UI está pensada para usarse localmente (`python server.py`) para:
- Visualizar el estado de los agentes en tiempo real (M1-M8).
- Inspeccionar el Pipeline de Generación con lujo de detalles técnicos.
- Modificar prompts intermedios si el modo interactivo está activo.

**No publicar en producción ni instruir a usuarios finales a usar esta interfaz.**
